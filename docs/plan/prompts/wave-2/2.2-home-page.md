## Mission
Build a memorable, fast home page that introduces Agustin in five seconds and sends visitors to Bio, Projects and Experiments.

## Context to load first
`docs/plan/00-README.md`, `01-architecture.md` (§3 Home, §4, §5), `02-shared-contracts.md`, `04-agent-loop-protocol.md`, handoffs `1.1`, `1.2`, `1.3`

## You own
`src/app/page.tsx`, `src/components/home/**`, `tests/unit/home/**`, `docs/handoffs/2.2.md`

## Tasks
1. `page.tsx` is a **Server Component** that composes sections. Only leaf components that animate are client components (via motion primitives).
2. **`Hero`**
   - Eyebrow (mono): `profile.location` · "Available for …" only if 1.2 exposes a status. Otherwise leave it out.
   - `h1`: `profile.name`, with `profile.role` below in `GradientText`, at display size (`--text-display`).
   - `profile.tagline` in muted text.
   - CTAs: `Button` → `/projects/` ("View projects"), `Button variant="outline"` → `/bio/` ("Read bio"), and `ContactCTA`.
   - Background: a decorative OKLCH gradient mesh (2–3 blurred radial blobs using `--brand*` tokens, `aria-hidden`, `pointer-events-none`). An optional slow drift with `ParallaxLayer` is turned off for reduced motion. **No canvas/WebGL** (perf budget).
   - The avatar (`next/image`, `priority`, 160px, ring in brand colour) sits beside the heading on ≥ md and above it on mobile.
3. **`ImpactStrip`**: 4 `achievements` in a responsive grid (2×2 mobile, 4×1 desktop). Each shows `CountUp` + unit, a label and a short description. Wrap in `Stagger`.
4. **`FeaturedProjects`**: `SectionHeading` "Selected projects" + `getFeaturedProjects(3)` as cards (cover image, title, summary, `TagList` of stack (max 4), link to `/projects/[slug]/`), a `HoverLift` wrapper, and a "All projects →" link. If a project title starts with `TODO`, still render it (placeholders are expected on staging).
5. **`LatestExperiments`**: `getLatestExperiments(4)` in a compact 2-col grid (title + one-liner + year + external icon) using `ExternalLink`, plus "All experiments →".
6. **`ContactBand`**: a full-width `bg-signature` band at low opacity with a headline ("Let's build something"), a short line and `ContactCTA`.
7. `metadata`: title = `siteConfig.title` (absolute), description = `siteConfig.description`.
8. Tests: hero renders name and role; the impact strip renders 4 items with the correct final values; featured renders ≤ 3 cards linking to slug routes.
