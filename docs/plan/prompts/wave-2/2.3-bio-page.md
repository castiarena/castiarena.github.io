## Tasks
1. `bio/page.tsx` is a Server Component. Section order and anchor ids: `#about`, `#experience`, `#achievements`, `#skills`, `#training`.
2. **`BioHeader`**: 2-col on ≥ md. Left: `PageHeader` (eyebrow "Bio", title = name, description = role · years), location with a MapPin icon, social buttons, and a **Download CV** `Button` (`href={profile.cvHref}`, `download`, Download icon, shows "PDF · 1.6 MB"). Right: avatar (`next/image`, 280px, rounded-3xl, subtle gradient ring).
3. **`Summary`** (`#about`): `profile.summary` paragraphs, `max-w-prose`, and the first paragraph slightly larger.
4. **`ExperienceTimeline`** (`#experience`)
   - Semantic `<ol>` with each role as an `<li>` wrapped in `<article>`.
   - A vertical line with a gradient (`bg-signature` 2px) and a dot per role; the dot fills as the item enters view (Motion, reduced-motion safe).
   - Each item: `h3` title, company (link if `companyUrl`, via `ExternalLink`), `<time dateTime>` range via `formatRange` + `durationLabel` in mono, intro paragraph, highlights `<ul>`, optional stack `TagList`.
   - Desktop: dates in a left gutter column. Mobile: dates above the title.
   - `Reveal` per item.
5. **`Achievements`** (`#achievements`): 4 `Card`s with `CountUp` metric, title, description, and `Stagger`.
6. **`Skills`** (`#skills`): 3 groups as columns (stacked on mobile), group label as `h3`, and skills as `Badge`s. Leadership badges use a different variant so the frontend/leadership balance is visible.
7. **`Training`** (`#training`): a simple list of course title and provider, linked if `href`.
8. **In-page nav** (≥ lg): a sticky side list of section anchors that highlights the active section with `IntersectionObserver` (client leaf). Hidden on mobile.
9. `metadata`: title "Bio", a description built from the first summary sentence, and `alternates.canonical: '/bio/'`.
10. Tests: timeline renders 4 roles in newest-first order; each role shows all highlights; the CV link has a `download` attribute and the correct href; section ids exist.
