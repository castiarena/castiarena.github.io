## Mission
Show bigger work as scannable case studies: an index with rich cards and scroll-driven reveals, plus a statically generated detail page per project.

## Context to load first
`docs/plan/00-README.md`, `01-architecture.md` (§1 dynamic route rules, §3 Projects), `02-shared-contracts.md`, `04-agent-loop-protocol.md`, handoffs `1.1`, `1.2`, `1.3`

## You own
`src/app/projects/**`, `src/components/projects/**`, `public/images/projects/**`, `tests/unit/projects/**`, `docs/handoffs/2.5.md`

## Tasks
1. **Placeholder covers**: for each slug in `projects.ts` that has no real image, create `public/images/projects/<slug>.svg` (1600×1000). It is an abstract OKLCH gradient composition with the project title in large type, and each file is under 20 KB. Real screenshots replace these later.
2. **`/projects/` index** (Server Component)
   - `PageHeader` (eyebrow "Work", title "Projects", description).
   - Projects sorted by `order`, shown as **large alternating rows** on ≥ md (image left/right) and stacked cards on mobile.
   - Each row: cover (`next/image`, rounded, border), index number in mono (`01`, `02`…), title `h2`, summary, role · period, stack `TagList`, and "Read case study →" linking to the detail page. Add live/repo icon links if present.
   - Motion: `Reveal` per row plus a subtle parallax on the cover (`ParallaxLayer offset={40}`), both turned off for reduced motion.
3. **`/projects/[slug]/`**
   - `export const dynamicParams = false`, `generateStaticParams = () => getAllProjectSlugs().map(slug => ({ slug }))`.
   - `params` is a **Promise** in Next 16: `const { slug } = await params`.
   - Layout: breadcrumb (Projects / title), hero with title, summary, meta grid (Role, Period, Stack), link buttons (Live, Repository, Case study) shown only if present, and a full-width cover.
   - Body sections: **The problem** (`problem`), **Approach** (numbered `approach` list), **Outcomes** (`outcomes` as highlighted cards; large text for any sentence starting with a number/percentage), and **Gallery** (grid; click opens shadcn `Dialog` lightbox with prev/next via arrow keys, focus trapped, alt text visible as caption).
   - Footer nav: previous/next project by `order`, plus "All projects".
   - `generateMetadata`: title = project title, description = summary, `openGraph.images` = cover, canonical `/projects/<slug>/`.
4. If a project has `TODO(agustin)` copy, show a small "Draft" badge on its detail hero **only when `process.env.NEXT_PUBLIC_DEPLOY_ENV !== 'production'`**, so drafts are flagged on Vercel previews. Production builds set that variable (see `deploy-pages.yml`), and agent 4.1 blocks release while any `TODO(agustin)` remains.
5. Tests: index sorted by order; the detail page renders all approach/outcome items; prev/next wrap correctly; link buttons hidden when links are missing; `generateStaticParams` returns every slug.

## Acceptance criteria
- [ ] Standard gate passes, and `out/projects/<slug>/index.html` exists for **every** slug
- [ ] Visiting a non-existent slug on `pnpm start` serves `404.html`
- [ ] The gallery lightbox is fully keyboard operable (Playwright: open with Enter, ← → navigate, Esc closes, focus returns)
- [ ] Each placeholder SVG is ≤ 20 KB, and every `img` has non-empty `alt`
- [ ] Screenshots (index + one detail) 375/1280 × light/dark in `docs/handoffs/assets/2.5/`
