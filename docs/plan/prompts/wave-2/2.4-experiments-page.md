## Mission
A playful but tidy gallery of small web experiments that link out to live sites, with tag filtering that works in a static export.

## Context to load first
`docs/plan/00-README.md`, `01-architecture.md` (§1 rules, §3 Experiments), `02-shared-contracts.md`, `04-agent-loop-protocol.md`, handoffs `1.1`, `1.2`, `1.3`

## You own
`src/app/experiments/**`, `src/components/experiments/**`, `public/images/experiments/**`, `tests/unit/experiments/**`, `docs/handoffs/2.4.md`

## Tasks
1. `experiments/page.tsx` is a Server Component: `PageHeader` (eyebrow "Lab", title "Experiments", description "Small things I built to learn, test an idea, or just for fun."). It passes `experiments` and `getExperimentTags()` to a client `ExperimentsGallery`.
2. **`ExperimentsGallery`** (`'use client'`)
   - Tag filter: shadcn `ToggleGroup type="multiple"` with an "All" reset; the counts show next to each tag.
   - The selected tags sync to `?tag=a&tag=b` with `useSearchParams` + `router.replace(…, { scroll: false })`. **Wrap the gallery in `<Suspense>` in the page**, as a static export requires for `useSearchParams`.
   - Filtering uses AND semantics, shows an empty state with a reset button, and `aria-live="polite"` announces "N experiments shown".
   - The grid is responsive (1/2/3 columns), and card enter/exit uses Motion `AnimatePresence` + `layout` (reduced-motion safe).
3. **`ExperimentCard`**
   - The whole card is a single link (`ExternalLink` semantics) with the title as the accessible name; avoid nested interactive elements, and place `sourceHref` as a separate small link *outside* the main link area.
   - Image: `next/image` 16:10 with `sizes`. If `image` is missing, render a **generated placeholder** (a deterministic OKLCH gradient from a hash of the slug plus the title initials) instead of a broken image.
   - Meta row: year (mono) and `TagList`.
   - `HoverLift`, with a subtle image zoom on hover that is turned off for reduced motion.
4. Placeholder images: none are required. The generated gradient covers missing ones.
5. `metadata`: title "Experiments", description, canonical `/experiments/`.
6. Tests: filter by one tag shows only matching; two tags use AND; reset shows all; URL params initialise state; the placeholder gradient is deterministic for the same slug.
