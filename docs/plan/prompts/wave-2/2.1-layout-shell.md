# Agent 2.1 — Layout Shell (header · mobile nav · footer · theme · 404)

| Wave | Mode | Depends on | Unblocks |
|---|---|---|---|

## Mission
Build the global frame every page lives in: root layout with providers and fonts, sticky responsive header, mobile nav sheet, theme toggle, footer, skip link and a styled 404.

## Context to load first
`docs/plan/00-README.md`, `01-architecture.md` (§3 Global, §4, §5), `02-shared-contracts.md`, `04-agent-loop-protocol.md`, handoffs `0.1`, `1.1`, `1.3`

## You own
`src/app/layout.tsx`, `src/app/not-found.tsx`, `src/components/layout/**`, `tests/unit/layout/**`, `docs/handoffs/2.1.md`, and adding `next-themes` to deps.

## Do not touch
Page files, `components/ui` (need a new primitive → CCR), contact internals (you only *render* `<ContactDialog />` from `@/components/contact`).

## Tasks
1. **`layout.tsx`**
   - Fonts from `@/components/shared/fonts` → `className={`${geistSans.variable} ${geistMono.variable}`}` on `<html lang="en" suppressHydrationWarning>`.
   - `<body className="min-h-dvh bg-background text-foreground font-sans antialiased">`
   - Order: `ThemeProvider` → `MotionProvider` → `SkipLink` → `SiteHeader` → `<main id="content" tabIndex={-1}>` → `SiteFooter` → `<Toaster />` (sonner, for 2.6).
   - Keep the `metadata` export from 0.1 (3.1 will extend it) and add `viewport` export with `themeColor` for light/dark.
2. **`ThemeProvider`** (`'use client'`): `next-themes` with `attribute="class"`, `defaultTheme="dark"`, `enableSystem`, `disableTransitionOnChange`.
3. **`ThemeToggle`**: shadcn `Button variant="ghost" size="icon"` that cycles light → dark → system, with Sun/Moon/Laptop icons, `aria-label` showing the current state, and no hydration mismatch (render a same-size placeholder until mounted).
4. **`SiteHeader`**
   - Sticky, `backdrop-blur`, border appears after scrolling 8px (tiny client hook).
   - Left: name as home link in mono, with a small gradient dot.
   - Center (≥ md): shadcn `NavigationMenu` from `siteConfig.nav`, active link from `usePathname()` (compare with trailing slash) with `aria-current="page"` and an animated underline (Motion `layoutId`, reduced-motion safe).
   - Right: `ThemeToggle`, `<ContactDialog trigger={<Button size="sm">Contact</Button>} />`.
   - Optional thin `ScrollProgress` from motion barrel if 1.3 shipped it.
5. **`MobileNav`** (< md): shadcn `Sheet` from the right, the same nav links (large tap targets ≥ 44px), socials, and a Contact button. It closes on route change and returns focus to the trigger.
6. **`SiteFooter`**: `Container`, socials from `profile.socials` (via `ExternalLink` for external), the "Built with Next.js · Deployed on GitHub Pages" note linking `siteConfig.repo`, and © year computed at build time.
7. **`SkipLink`**: "Skip to content" link to `#content`, visible on focus.
8. **`not-found.tsx`**: a big gradient "404", a short friendly message, and links to Home, Projects, Experiments. It exports as `out/404.html`.
9. Tests: nav renders all `siteConfig.nav` items; `aria-current` is set for the active path (mock `usePathname`); the skip link targets `#content`; ThemeToggle has an accessible name.
