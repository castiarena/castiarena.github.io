## Tasks
1. **Production smoke** (`tests/e2e/production.spec.ts`, `baseURL` from `PROD_URL` env, default `https://castiarena.github.io`, and skipped unless `PROD_URL` is set):
   - 200 + correct `<title>` for `/`, `/bio/`, `/projects/`, `/experiments/`, every `/projects/<slug>/`
   - `/bio` (no slash) resolves to `/bio/`
   - `/does-not-exist/` serves the custom 404 content
   - `/cv/agustin-castiarena-resume.pdf` → `application/pdf`
   - `/sitemap.xml`, `/robots.txt` reachable; sitemap URLs all return 200
   - Canonical tags point to production; there's no `noindex` on production pages
   - Every `_next/static` asset referenced on `/` returns 200 (no underscore/Jekyll issue)
   - No console errors on any route
2. Run the production smoke + axe + Lighthouse (mobile and desktop) against production and compare to the 3.2 staging numbers. Flag any regression > 5 points.
3. **Other Pages sites still work**: for every repo from the 3.3 collision audit, request `https://castiarena.github.io/<repo>/` and confirm it's unchanged (status code same as the 3.3 baseline).
4. **Share preview check**: fetch OG tags for `/`, `/bio/` and one project, and download each `og:image` (200, 1200×630).
5. **Uptime workflow** `.github/workflows/uptime.yml`: `schedule: '17 */6 * * *'` + `workflow_dispatch`. Runs `production.spec.ts` with `PROD_URL`, and on failure opens (or updates) a single GitHub issue labelled `uptime`, using `gh issue`, with `permissions: issues: write`.
6. **Search Console handoff**: write the steps for the human to verify `https://castiarena.github.io/` in Google Search Console (HTML tag method → requires adding `verification.google` to root metadata. Prepare that as a ready PR with a placeholder token, **not merged**) and submit `sitemap.xml`.
7. **`docs/POST-LAUNCH-REPORT.md`**: the Definition of Done checklist from `00-README.md` with evidence per item, the before/after comparison, and any regressions.
8. **`docs/BACKLOG.md`**: remaining `Needs human input` items, deferred CCRs, 3.2 findings not fixed, and ideas (analytics via Plausible/Umami, blog/notes section, i18n ES/EN, real project screenshots, GSAP pinned case-study timeline, Vercel mirror domain).
9. Clean up worktrees (`git worktree prune`) and delete merged `agent/*` branches on origin (list them first in the handoff; delete only merged ones).
