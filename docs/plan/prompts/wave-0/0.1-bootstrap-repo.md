## Mission
Turn `castiarena/castiarena.github.io` into a Next.js 16 static-export project on a new `next` integration branch. Keep a frozen copy of the current Vite site. Create **every shared contract and stub** from `docs/plan/02-shared-contracts.md`, so Wave 1 and 2 agents can work in parallel without waiting on each other. The site should build and deploy as plain placeholder pages when you finish.

- `docs/plan/00-README.md`, `docs/plan/01-architecture.md`, `docs/plan/02-shared-contracts.md`, `docs/plan/03-deployment-flow.md`, `docs/plan/04-agent-loop-protocol.md`

## You own
Everything in the repo during this wave. Later agents own their paths per the matrix in 02 §5. Create the files, but keep implementations **minimal**: stubs, not features.

## Tasks

### A. Repository & branches
1. `git clone git@github.com:castiarena/castiarena.github.io.git portfolio-v2 && cd portfolio-v2` (use HTTPS with `gh auth` if SSH isn't set up).
2. Record the current state for rollback: the default branch, the last commit SHA, and (via `gh api repos/castiarena/castiarena.github.io/pages`) the Pages source branch/folder. Write it to `docs/DEPLOYMENT-legacy.md`.
3. Freeze legacy: `git tag legacy-v1 origin/main && git push origin legacy-v1`, then `git push origin origin/main:refs/heads/legacy-v1`.
4. Create the integration branch: `git switch -c next origin/main && git push -u origin next`.
5. Create your working branch: `git switch -c agent/0.1-bootstrap`.

### B. Clean slate
6. `git rm -r` every tracked legacy file (Vite `src/`, `styles/`, `texts/`, `images/`, `scripts/`, `docs/`, `index.html`, `vite.config.ts`, tsconfigs, `yarn.lock`, `.eslintrc`, `.prettierrc`, `ico.svg`, …). Keep `LICENSE` if present. The legacy code stays available on `legacy-v1`.

### C. Scaffold Next.js 16
7. Scaffold into a temp dir, then move the files in:
   `pnpm create next-app@latest ../_scaffold --ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm --yes`
   Check that it produced **Next 16.x, React 19.2.x, Tailwind v4** (`@tailwindcss/postcss`, `@import "tailwindcss"` in `globals.css`). If the CLI flags differ, run `--help` and adapt.
8. Add `.nvmrc` → `24`. In `package.json`, add `"packageManager": "pnpm@<installed version>"` and `"engines": { "node": ">=24" }`.
9. Replace `next.config.ts` with the exact config in `01-architecture.md §1`.
10. `tsconfig.json`: `"strict": true`, `"noUncheckedIndexedAccess": true`, and the `@/*` alias.
11. Scripts:
    ```json
    {
      "dev": "next dev",
      "build": "next build",
      "start": "pnpm dlx serve@latest out -l 4173",
      "lint": "eslint .",
      "typecheck": "tsc --noEmit",
      "test": "vitest",
      "e2e": "playwright test",
      "format": "prettier --write .",
      "format:check": "prettier --check ."
    }
    ```
    (Next 16 removed `next lint`, so ESLint runs through the flat config from create-next-app.)
12. Prettier: `prettier.config.mjs` with `prettier-plugin-tailwindcss`, and `.prettierignore` covering `out`, `.next`, `pnpm-lock.yaml`, `docs/plan`.
13. Unit tests: `vitest`, `@vitejs/plugin-react`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, `vite-tsconfig-paths`. Create `vitest.config.ts` (jsdom, `tests/unit/**/*.test.ts?(x)`, setup file `tests/setup.ts`).
14. E2E: `@playwright/test`, `@axe-core/playwright`. In `playwright.config.ts`, `webServer.command` = `E2E_SKIP_BUILD` ? `pnpm start` : `pnpm build && pnpm start`, on port 4173, with Chromium projects for mobile (375) and desktop (1280). Seed `tests/e2e/smoke.spec.ts`, which visits `/`, `/bio/`, `/experiments/`, `/projects/` and expects status 200 and one `h1`.
