## Mission
Build the visual foundation: OKLCH design tokens and dark/light themes in Tailwind v4, shadcn/ui set up with every primitive Wave 2 needs, and real implementations of the `src/components/shared/*` stubs. Also add a hidden style-guide route so reviewers can see everything in one place on the Vercel preview.

## Context to load first
`docs/plan/00-README.md`, `01-architecture.md` (§4 Design direction, §5 rules), `02-shared-contracts.md` (§4, §5), `04-agent-loop-protocol.md`, `docs/handoffs/0.1.md`

## You own
`src/app/globals.css`, `components.json`, `src/components/ui/**`, `src/components/shared/**`, `src/app/styleguide/**` (temporary, see task 9), `tests/unit/shared/**`, `docs/handoffs/1.1.md`, and adding deps to `package.json`.

## Do not touch
`layout.tsx` (2.1), `src/components/motion/**` (1.3), content, routes other than `styleguide`.

## Tasks
1. **shadcn init** for Tailwind v4: `pnpm dlx shadcn@latest init` (style: new-york or the current default, base colour: neutral, CSS variables: yes, RSC: yes, alias `@/components`). Check that `components.json` points to `src/app/globals.css` and that `tw-animate-css` is installed.
2. **Tokens in `globals.css`**:
   - `@import "tailwindcss"; @import "tw-animate-css";`
   - `@custom-variant dark (&:is(.dark *));`
   - `:root` (light) and `.dark` blocks with every shadcn variable **in OKLCH** (`--background`, `--foreground`, `--card`, `--popover`, `--primary`, `--secondary`, `--muted`, `--accent`, `--destructive`, `--border`, `--input`, `--ring`, `--radius`), plus the brand tokens `--brand`, `--brand-2`, `--brand-3` from 01 §4.
   - `@theme inline { --color-*: var(--*); --font-sans: var(--font-geist-sans); --font-mono: var(--font-geist-mono); }` so utilities such as `bg-brand` and `text-muted-foreground` work.
   - Utilities: `@utility bg-signature { background-image: linear-gradient(in oklch 120deg, var(--brand), var(--brand-2), var(--brand-3)); }`, a matching `text-signature` (gradient + `bg-clip-text` + transparent), and `@utility container-page` (max-w-6xl, mx-auto, px-4 sm:px-6).
   - A fluid type scale using `clamp()` for `--text-display`, `--text-h1`, `--text-h2`.
   - Base layer: `html { color-scheme: light dark }`, `:focus-visible` ring using `--ring`, `::selection` using brand at 30% alpha, and `@media (prefers-reduced-motion: reduce)` that disables smooth scroll.
3. **Contrast check**: write `tests/unit/shared/contrast.test.ts`. It parses the OKLCH tokens (use `culori`) and asserts WCAG contrast ≥ 4.5:1 for `foreground/background`, `muted-foreground/background`, and `primary-foreground/primary` in **both** themes.
4. **Install shadcn primitives** (only you do this): `button badge card navigation-menu sheet dialog form input textarea label separator tooltip toggle-group skeleton sonner`. Add `scroll-area` and `aspect-ratio` if needed by 01 §3.
5. **Implement shared components** (02 §4 signatures, add optional props only):
   - `Container`: uses `container-page`.
   - `PageHeader`: eyebrow in mono uppercase, `h1` with an optional `GradientText` span, and a description in `text-muted-foreground max-w-prose`.
   - `SectionHeading`: `h2` with an anchor `id` and a hover `#` link.
   - `TagList`: shadcn `Badge variant="secondary"` items in a `ul` with `aria-label="Tags"`.
   - `ExternalLink`: `target="_blank" rel="noopener noreferrer"`, a lucide `ArrowUpRight` icon (`aria-hidden`), and a `sr-only` "(opens in a new tab)".
   - `GradientText`: `text-signature`.
6. **Fonts**: export `geistSans` and `geistMono` from `src/components/shared/fonts.ts` via `next/font/google` (or the `geist` package), with `variable` names `--font-geist-sans` / `--font-geist-mono`. 2.1 wires them into `<html>`. Note this in the handoff.
7. Unit tests for `ExternalLink` (rel/target/sr-only text) and `TagList` (renders N items).
8. Add `lucide-react`, `culori` (+ `@types/culori`), and whatever shadcn requires.
9. **Style guide**: `src/app/styleguide/page.tsx` shows the colour swatches (both themes, using a local `.dark` wrapper), the type scale, every installed primitive, and every shared component. Set `metadata.robots = { index: false }`. **Agent 4.1 deletes this route before release.**
