# Agent 1.3 — Motion Primitives (Motion for React)

## Mission
Build a small, accessible, performance-safe set of animation primitives with **Motion** (`motion` package, `motion/react` import). Page agents should get scroll reveals and hover effects by wrapping content, without writing animation code of their own.

## Context to load first
`docs/plan/00-README.md`, `01-architecture.md` (§4 Motion budget, §5), `02-shared-contracts.md` (§4 motion row), `04-agent-loop-protocol.md`, `docs/handoffs/0.1.md`

## You own
`src/components/motion/**`, `tests/unit/motion/**`, `src/app/motion-lab/**` (temporary demo route), `docs/handoffs/1.3.md`, and adding `motion` to deps.

## Tasks
1. `pnpm add motion`. Check React 19 compatibility.
2. **`MotionProvider`** (`'use client'`): `<MotionConfig reducedMotion="user" transition={{ duration: 0.5, ease: [0.22, 1, 0.36, 1] }}>` wrapping `LazyMotion features={domAnimation} strict`. **Use `m.*` components everywhere** (not `motion.*`) to keep the bundle small.
3. **`Reveal`**: fades in and moves up by `y` (default 16px) on entering the viewport. `whileInView`, `viewport={{ once: true, amount: 0.2 }}`, optional `delay`, polymorphic `as` (`div|section|li`). Choose a hydration strategy that (a) keeps server-rendered HTML **visible** (no `opacity:0` in the static HTML, for no-JS users and crawlers), and (b) avoids a visible→hidden flicker for elements already in the viewport at hydration (skip the animation for those). Explain the choice in the handoff.
4. **`Stagger` / `StaggerItem`**: parent variants with `staggerChildren` (default 0.06), children reuse the Reveal variants.
5. **`HoverLift`**: `whileHover={{ y: -4 }}`, `whileTap={{ scale: 0.98 }}`, and a focus-visible equivalent (lift on `:focus-within` via CSS class) so keyboard users get the same feedback.
6. **`CountUp`**: animates from 0 to `value` when in view using `useInView` + `animate()` from `motion`, and renders the final value in SSR HTML. Has `aria-label` with the final value, and the animated digits are `aria-hidden`. With reduced motion it shows the final value immediately.
7. **Optional extra** (add to barrel as new exports, which is allowed): `ScrollProgress` (top bar using `useScroll` + `useSpring`) and `ParallaxLayer({ children, offset?: number })` using `useScroll`/`useTransform`, turned off for reduced motion.
8. Every component: only `transform`/`opacity` animated, no layout thrash, `'use client'` at file top, no default exports.
9. **Demo route** `src/app/motion-lab/page.tsx` (noindex) shows every primitive. **4.1 deletes it before release.**
10. Tests (Vitest + jsdom, mock `IntersectionObserver`): each primitive renders children; `CountUp` SSR output contains the final value; with `matchMedia('(prefers-reduced-motion: reduce)')` mocked, no transform style is applied.
