## Tasks
1. **`src/lib/seo.ts`**: `absoluteUrl(path)` built on `siteConfig.url`, and `buildMetadata({ title, description, path, image? })` → `Metadata` with `alternates.canonical`, `openGraph` (type, url, siteName, locale, images), `twitter` (`summary_large_image`).
2. **Root `layout.tsx` metadata**: `metadataBase`, `title: { default: siteConfig.title, template: '%s · Agustin Castiarena' }`, description, `authors`, `creator`, `keywords` (from skills), `robots: { index: true, follow: true }`, `icons`, and `openGraph`/`twitter` defaults.
3. Refactor each page's metadata export to use `buildMetadata`. **Change only the metadata exports.**
4. **`sitemap.ts`** (`export const dynamic = 'force-static'`): `/`, `/bio/`, `/projects/`, `/experiments/`, and every `/projects/<slug>/`, with `lastModified` = build time. Exclude `styleguide` and `motion-lab` if they still exist (V1 deletes them).
5. **`robots.ts`** (`force-static`): allow all, disallow `/styleguide/` and `/motion-lab/`, and point `sitemap` to the absolute URL.
6. **`manifest.ts`** (`force-static`): name, short_name "Agustin C.", theme/background colours matching the dark tokens, icons.
7. **Icons**: `icon.svg`, a monogram "AC" on the signature gradient that works at 16px, and `apple-icon.png` 180×180 rendered from the same design (commit the PNG).
8. **OG images** with `ImageResponse` from `next/og` at 1200×630: dark background, gradient accent, name, route title, and a short line. Per-project OG shows the project title and stack. Check that they **prerender during `next build` under `output: 'export'`**. If a route fails to prerender, generate static PNGs with a build-time script (`scripts/og/*.mjs` — CCR to 1.4 ownership, or commit the PNGs to `public/og/`) and reference them in metadata. Document which approach you used.
9. **JSON-LD** via `<JsonLd data={…} />` (`<script type="application/ld+json">`, safely serialised):
   - `/` and `/bio/`: `Person` (name, jobTitle, url, image, sameAs socials, address locality/country, knowsAbout skills, alumniOf is **not** in the CV so leave it out, worksFor is also left out unless 05 confirms the current employer).
   - `/projects/<slug>/`: `CreativeWork` (name, description, author → Person, image, url).
   - `WebSite` on `/`.
10. Tests: `buildMetadata` canonical/OG output; the sitemap includes every slug and excludes the temporary routes; JSON-LD is valid JSON and contains no phone number.

## Acceptance criteria
- [ ] Standard gate passes with `VERIFY_STRICT=1 node scripts/verify-export.mjs`
- [ ] `out/sitemap.xml`, `out/robots.txt`, `out/manifest.webmanifest` exist; every canonical link in `out/**/*.html` starts with `https://castiarena.github.io/` and ends with `/`
- [ ] Every page has a unique `<title>` and a `meta[name=description]` of 50–160 chars (a script check over `out/`)
- [ ] OG image files exist for `/`, `/bio/`, `/projects/`, `/experiments/` and each project; each is 1200×630 (check with `sharp` or `image-size`)
- [ ] JSON-LD blocks pass `schema-dts` type checks at compile time, and a quick validation with `pnpm dlx structured-data-testing-tool` (or equivalent) shows no errors
- [ ] Lighthouse SEO ≥ 95 on `/`, `/bio/`, one project page
