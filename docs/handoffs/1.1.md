## What I built

- **shadcn/ui init** for Tailwind v4 (`components.json`: style `radix-nova`, base colour neutral, CSS variables, RSC, `@/components` aliases, lucide icons). `tw-animate-css` is installed and imported.
- **OKLCH design tokens** in `src/app/globals.css`: light (`:root, .light`) and dark (`.dark`) palettes for every shadcn variable plus `--brand`, `--brand-2`, `--brand-3`, `--brand-foreground`. `@theme inline` maps them to utilities. Also a fluid `clamp()` type scale, the `bg-signature` / `text-signature` / `container-page` utilities, and a base layer (colour-scheme, focus ring, selection, reduced motion).
- **Contrast test** (`tests/unit/shared/contrast.test.ts`, culori): the 3 required pairs plus 9 more are ≥ 4.5:1 in both themes. It also checks that every colour token is OKLCH, that there is no hex/rgb, and that the dark brand values match 01 §4.
- **Primitives** in `src/components/ui/`: button, badge, card, navigation-menu, sheet, dialog, **field** (replaces `form`, see Decisions), input, textarea, label, separator, tooltip, toggle-group (+ toggle), skeleton, sonner, scroll-area, aspect-ratio.
- **Shared components** (`@/components/shared`): real implementations of `Container`, `PageHeader`, `SectionHeading`, `TagList`, `ExternalLink` and `GradientText`. Every 02 §4 signature is unchanged. Only optional props were added.
- **Fonts:** `src/components/shared/fonts.ts` exports `geistSans` / `geistMono` (next/font/google, `--font-geist-sans` / `--font-geist-mono`).
- **Style guide:** `/styleguide/` (`robots: noindex, nofollow`) shows swatches for both themes side by side, the type scale, every primitive (with working dialog, sheet, tooltip, toast and toggles), every shared component, and a temporary "Preview dark theme" button. **4.1 deletes `src/app/styleguide/`.**

## Utility classes for page agents

| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `bg-signature`                                                              | Signature gradient background (`linear-gradient(in oklch 120deg, brand, brand-2, brand-3)`)                             |
| `text-signature`                                                            | Gradient text (`background-clip: text`, transparent fill, `CanvasText` in forced-colours mode). Prefer `<GradientText>` |

| `bg-brand` · `text-brand` · `text-brand-2` · `from-brand-3` …               | Brand colours (every Tailwind colour utility works with `brand`, `brand-2`, `brand-3`, `brand-foreground`)              |

## Decisions

- **Style `radix-nova` (shadcn CLI 4.21 default, "Nova · Lucide / Geist") on the Radix base.** The CLI no longer offers `new-york`. I chose Radix over Base UI because 02 §5 tells wave-2 agents to fall back to Radix primitives.
- **`form` → `field`.** In the current registry, `form` for `radix-nova` is an empty item: the CLI "adds" it and writes no files. `field` (`Field`, `FieldLabel`, `FieldDescription`, `FieldError`, `FieldGroup`, `FieldSet`…) is its replacement and works with any form library or with plain `<form>`. **2.6:** build the contact form with `Field*` + `Input`/`Textarea`. If you want react-hook-form, add it yourself (`pnpm add react-hook-form`) and wire it with `Controller` + `Field`.
- **`cn` stays in `@/lib/utils`.** The new registry writes `import { cn } from "cn"` (a new npm package) and `shadcn init` rewrote `src/lib/utils.ts` to re-export it. I reverted `utils.ts` (0.1-owned), removed the `cn` package, and pointed every primitive at `@/lib/utils`. **If anyone runs `shadcn add` later, rewrite the import the same way.**
- **`shadcn` is a devDependency.** It is only needed at build time for `@import 'shadcn/tailwind.css'` (the `data-open`/`data-closed`/… variants and accordion keyframes the nova components use). Rejected alternative: inline that file, which would be large and drift from upstream.
- **Light brand values are deepened** (`--brand` L 0.52, `--brand-2` L 0.56, `--brand-3` L 0.52), so brand text/links and gradient text stay legible on white. Dark (the default) uses the exact 01 §4 values.
- **Dropped shadcn `chart-*` and `sidebar-*` tokens** because no planned route uses them. `shadcn add chart|sidebar` would bring them back.
- **`:root, .light`** share the light palette, so a subtree can force light inside a dark page (used by the swatches).
- **Reduced motion** disables smooth scroll _and_ shortens CSS animations/transitions to 0.01ms (the tw-animate dialog/sheet animations). JS animations from Motion are 1.3's responsibility.
- **Fonts are not re-exported from the `@/components/shared` barrel.** `next/font` needs the Next compiler, so importing it through the barrel would break Vitest. Import from `@/components/shared/fonts`.
- **Style guide theme preview** toggles the `dark` class directly. It uses `useSyncExternalStore` over a MutationObserver, so it stays in sync with 2.1's next-themes toggle once that exists.
