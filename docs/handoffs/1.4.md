## Decisions

- **`VERIFY_STRICT: '0'` is written on the `verify-export` step in both workflows**, so agent 3.1's "flip `VERIFY_STRICT=1`" is a one-character change on a known line. The alternative was leaving the variable out, which would make 3.1 add a new line instead of flipping one.
- **`include-hidden-files: true`** on `upload-artifact` (`out`) and `upload-pages-artifact`. Both skip dotfiles by default, so `out/.nojekyll` would otherwise be missing from the deployed site despite the `touch` in 03 §4.
- **Added `type: string` to the dispatch input and `timeout-minutes`** to the deploy jobs (15/10), plus `retention-days: 7` on `playwright-report`. These are small hardening additions to 03 §4. Everything else matches 03 exactly.
- **verify-export extras:** besides the 03 list, it checks that `out/_next/static/` is not empty, that each `slug: '…'` value in `projects.ts` has its folder, and that there are no unexpected project folders. It also treats any `href|src|srcset="/<prefix>/_next/` as a basePath leak, in addition to the literal `/castiarena.github.io/` check. `out/404/index.html` and `out/_not-found/` (extra `next build` outputs) are neither required nor flagged. Project folders only count if they contain a non-empty `index.html`, so RSC `.txt` payloads don't matter. Paths resolve from the repo root, so the script works from any cwd. An optional `outDir` argument is accepted.
- **Rejected:** `actions/configure-pages` (injects a basePath, per 03 §4); pinning actions to SHAs (03 asks for majors, and Dependabot's `github-actions` updates keep them current).
- **Dependabot** commit prefixes are `chore(deps)` / `chore(ci)`, with a limit of 10 open npm PRs.
