## Decisions & scaffold deviations

- **Scaffold directory name:** `create-next-app` rejects `_scaffold` (npm names can't start with `_`), so it was scaffolded into a temp dir named `scaffold`. The demo SVGs in `public/`, the demo `page.tsx` and the scaffold README were dropped.
- **`vite-tsconfig-paths` not used.** Vitest 5 runs on Vite 8, which resolves tsconfig `paths` natively (`resolve.tsconfigPaths: true`) and warns that the plugin is redundant (its `tsconfck` dependency is deprecated). Rejected alternative: keep the plugin and live with the warning.
- **`@types/node` bumped from `^20` (scaffold) to `^24`** to match the Node 24 runtime.
- **No generated `PageProps` / `LayoutProps` globals.** They only exist after `next build`/`next typegen` creates `.next/types`, so `pnpm typecheck` (plain `tsc --noEmit`) failed on a fresh clone. The layout and `[slug]` page use explicit prop types instead (`params: Promise<{ slug: string }>`, awaited).
- **typedRoutes + trailing slashes:** typedRoutes only accepts slash-less paths (`"/bio"`), but the frozen `siteConfig.nav` uses `"/bio/"`. `SiteHeader` casts `item.href as Route`. `trailingSlash: true` still emits `/bio/` links. Downstream agents linking to `siteConfig.nav` hrefs must do the same (or use the slash-less literal, which Next rewrites to `/bio/`).
- **Prettier:** no semicolons, single quotes, trailing commas, width 100, plus the Tailwind plugin (`tailwindStylesheet: ./src/app/globals.css`). `src/content/types.ts` and `src/config/site.ts` are in `.prettierignore`, so they stay verbatim copies of `02`. Prettier reflowed the comment spacing in `next.config.ts` (whitespace only).
- **Content barrel:** also does `export type * from './types'` (additive, so `import type { Project } from '@/content'` works). Helper semantics: `getFeaturedProjects` = featured, sorted by `order`, sliced; `getAllProjectSlugs` = sorted by `order`; `getLatestExperiments` = `year` desc, stable for ties; `getExperimentTags` = unique, case-insensitive alphabetical. Non-positive limits return `[]`.
- **Playwright mobile project** uses Desktop Chrome at a 375×812 viewport (Chromium only, as specified). `reuseExistingServer` is on locally, off in CI.
- **Stub extras:** `Stagger.as` = `'div' | 'section' | 'ul' | 'ol'`; `Container.as` = `'div' | 'section' | 'header' | 'footer' | 'nav' | 'article'` (02 left the unions open). `ContactDialog` is a `mailto:` link that renders `trigger ?? 'Contact'`.
- **Fonts:** kept the scaffold's Geist / Geist Mono via `next/font/google` in `layout.tsx` (matches 01 §4). `globals.css` is untouched scaffold output for 1.1 to replace.
