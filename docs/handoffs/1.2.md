  - Realworld One: `https://realworld-one.com` (RealWorld One, XR for life sciences). The owner should confirm it's the same employer.
  - Westwing: `https://www.westwing.com` (Westwing Group site with the country selector). Rejected: a single-country shop such as `westwing.de`.
  - Mercado Libre: `https://www.mercadolibre.com` (regional country selector).
  - Course **The Good Parts of JavaScript and the Web**: `https://frontendmasters.com/courses/good-parts-javascript-web/` (currently redirects to `master.dev`, the same course page).
  - Course **Advanced React Patterns**: **no `href`**. `frontendmasters.com/courses/advanced-react-patterns/` now meta-refreshes to a different course (_A Tour of JavaScript & React Patterns_), so the original page can't be confirmed.
- **`stack` only where the CV names it:** Riverside `['GraphQL', 'Microservices']`, Westwing `['Micro frontends']`. Realworld One and Mercado Libre have none. The seed's `React`/`TypeScript` for Riverside was dropped because that role's CV text doesn't mention them.
- **Mercado Libre `intro` is `''`**: the CV has no intro for that role. The schema allows an empty `intro`. Renderers should skip it when it's empty.
- **The 10/2018 – 01/2020 gap** is not represented (see Needs human input).
- **Project placeholders reuse CV sentences verbatim** where they fit (summary, approach, one outcome). Everything else starts with `TODO(agustin):`, including titles and cover `alt`. No numbers are attributed to projects: the CV achievements don't name an employer, so linking "35%" to Riverside would be invented. `period` is derived from the CV dates.
- **Placeholder experiments** use `tags: ['TODO']` and `year: 2026`, so they sort first and are easy to spot.
- **Schema rules** beyond the prompt: kebab-case slugs, unique `order` for projects, unique ids for achievements and skill groups, unique course titles, `YYYY-MM` months with valid month numbers, `mailto:` required for `Email` socials, http(s) only for other URLs (this rejects `javascript:`), `cvHref` must be a PDF under `/cv/`, and `year` must be between 2000 and 2100.
- **Validation lives at import time of `@/content`**, not in `next.config.ts` (not owned). The build error names the path, for example `✖ duplicate slug "todo-experiment-1" (already used at index 0) → at experiments[1].slug`.
- **`durationLabel`** counts whole months between start and end (end month excluded), which is what the prompt's example needs (`2023-02 → 2026-07` = `3 yrs 5 mos`). A same-month range returns `'1 mo'`. `'present'` resolves against an optional `now` argument (default: build time).
- **Privacy regex vs dates:** `/\+?\d[\d\s-]{8,}\d/` matches full `YYYY-MM-DD` dates. Content files must therefore not contain full ISO dates, even in comments. Use `YYYY-MM` or words.

## Notes for downstream agents

- Import content **only in server components** and pass plain props to client components. Importing `@/content` from a `'use client'` file bundles zod plus the validation into the client.
- Helper usage:

```ts
import {
  profile,
  experiences,
  achievements,
  skillGroups,
  courses,
  getFeaturedProjects,
  getProjectBySlug,
  getAllProjectSlugs,
  getLatestExperiments,
  getExperimentTags,
} from '@/content'
import { durationLabel, formatMonth, formatRange } from '@/lib/format'

getFeaturedProjects() // 3 placeholder projects, by `order`
getProjectBySlug('micro-frontend-migration') // Project | undefined
getAllProjectSlugs() // ['recording-studio-architecture', 'vr-ar-healthcare-platform', 'micro-frontend-migration']
getLatestExperiments(4) // 3 TODO experiments (2026), then portfolio-v1 (2024)
getExperimentTags() // ['TODO', 'TypeScript', 'Vite']

formatMonth('2023-02') // 'Feb 2023'
formatRange('2023-02', '2026-07') // 'Feb 2023 — Jul 2026'
formatRange('2023-02', 'present') // 'Feb 2023 — Present'
durationLabel('2023-02', '2026-07') // '3 yrs 5 mos'
```

- **2.3 (Bio):** skip `experience.intro` when it's `''` (Mercado Libre). `experience.stack` is optional. `achievements[].metric` → `<CountUp value={m.value} suffix={m.unit} />` with `m.label` as the caption. `courses[].href` is optional.
- **2.4 (Experiments):** `image` is absent on every entry. Render a fallback. Titles containing `TODO(agustin)` are placeholders.
- **2.5 (Projects):** covers point to `/images/projects/<slug>.svg`, which you create. `links` is `{}` for all 3. `period` is set. `vr-ar-healthcare-platform.stack` is `['TODO(agustin): Stack']`.
- **Schema exports** for tests: `contentSchema`, `projectSchema`, `experimentSchema`, `experienceSchema`, … and `getContent()` from `@/content/schema`.
- **Adding content:** `pnpm test -- --run` covers the rules. The privacy test rejects any 10+ character digit run, including full `YYYY-MM-DD` dates, in `src/content/**`.
